Full-stack · PWA

Workout Logbook

An installable, offline-first web app for tracking sets, reps, weights, cardio, rest, and body weight.

  • Built-in 8-day training rotation that adapts to missed days instead of forcing a fixed schedule
  • Auto-starting rest timer with audio and vibration alerts, plus 1RM estimates against past performance
  • Cross-device sync with 30-day backups; optional Fitbit import via the Google Health API
  • Node.js
  • Express
  • Vanilla JS
  • Docker
  • Playwright

Predictive Battery Maintenance

Forecasts when a laptop battery will fall below 80% health, with an optimistic-to-pessimistic range.

R² 0.85model fit
~216 daysmean error vs 333 baseline
  • Simulates calendar and cycle aging across 3,000 laptops to train three quantile models (P10 / P50 / P90)
  • Reads real battery stats on macOS and serves a web dashboard plus a JSON API
  • Trained on simulated data, so results are estimates pending real-world validation
  • Python
  • Flask
  • scikit-learn
  • Quantile regression

Meeting Scheduler

A When2Meet-style app for coordinating schedules with friends, built as a team final project for a software engineering course.
